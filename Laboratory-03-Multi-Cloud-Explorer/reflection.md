# Reflection

1. Which cloud platform impressed you the most?
Google Cloud Platform impressed me the most, mainly because of how strong it is in AI and Kubernetes. I didn't know Google actually created Kubernetes until I did this research, and it made me understand why so many companies trust GCP for machine learning projects. It made me curious to try using it myself someday.

2. What similarities exist among AWS, Azure, and GCP?
All three platforms basically offer the same core categories of services, they just use different names for them. All of them have a virtual machine service, storage service, database service, and identity management tool. They also all use the idea of regions and zones to spread their data centers around the world so their services stay available even if one location has a problem.

3. How do business requirements influence cloud platform selection?
This activity really showed me that there's no single "best" cloud platform, it depends on what the client actually needs. A startup with a small budget might care more about free tiers and easy scaling, while a university that already uses Microsoft tools would care more about how well a platform connects to what they already have. Choosing a cloud provider is more about solving a specific problem than picking the most popular brand.

4. What did you learn from acting as a Cloud Solutions Consultant?
I learned that being a cloud consultant is not just about knowing a lot of technical facts, it's also about understanding the client's situation and matching it to the right tools. I had to think about budget, existing systems, and future growth for each client scenario instead of just recommending the same platform for everyone.

5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?
My portfolio now shows more than just basic Linux skills, it also shows that I can research, compare, and make recommendations like someone working in the cloud industry. Having research files, comparison tables, and client scenarios documented in Markdown makes my GitHub repository look more organized and professional than before.
