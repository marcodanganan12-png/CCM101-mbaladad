# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity is about learning the basics of working inside a Linux environment using KillerCoda. It covers creating a user account, checking system information, organizing files and folders using Linux commands, and documenting everything properly using Markdown and GitHub. This activity also helped me practice keeping a clean and organized portfolio, which is something I'll keep doing throughout the semester.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed
- Launched an Ubuntu 24.04 environment on KillerCoda.
- Created a new sudo user (`mbaladad`) and logged in.
- Gathered system information (distro, kernel, CPU, memory, disk space).
- Built a folder structure (Notes, Reports, Screenshots) in the home directory.
- Created and populated `about-me.md`.
- Created a public GitHub portfolio repository and organized it per
  the required structure.

## Linux Commands Used
- `sudo adduser`, `sudo usermod -aG sudo`, `su -`
- `whoami`, `pwd`, `hostname`
- `lsb_release -a`, `uname -r`, `lscpu`, `free -h`, `df -h`
- `mkdir -p`, `ls`, `cd`, `nano`, `cat`
- `git clone`, `git add`, `git commit`, `git push`

## Skills Learned
- Basic Linux user and permission management.
- Navigating and inspecting a Linux system.
- Organizing a professional file/folder structure.
- Writing technical documentation in Markdown.
- Version control fundamentals using Git and GitHub.
