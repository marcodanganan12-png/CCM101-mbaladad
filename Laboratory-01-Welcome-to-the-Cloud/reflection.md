# Reflection

This activity taught me a lot about using Linux, even the basic stuff like creating a user or checking system information. Before this, I only used the terminal a little bit, so typing commands like `adduser`, `usermod`, and `lscpu` felt new to me. I also learned how to organize files properly using folders and how to write documentation using Markdown, which I didn't really do before.

One challenge I faced was remembering the correct commands and their flags, since some of them look similar but do different things, like `su` and `sudo`. I also had a bit of trouble with `nano` at first because I wasn't used to saving and exiting using keyboard shortcuts instead of clicking buttons. I fixed this by just practicing the commands a few times until I got used to them.

Setting up the GitHub repository was also new to me, especially pushing files from the terminal using a personal access token instead of my normal password. It was confusing at first, but once I understood the steps, it made sense why developers use Git to keep track of their work.

Overall, I think these skills are important for cloud engineering because most cloud work is done through the terminal and not through a normal desktop interface. Knowing how to move around Linux, manage files, and use GitHub to save and organize work will probably be useful once we start doing more advanced topics like Docker and Kubernetes later in the course.
